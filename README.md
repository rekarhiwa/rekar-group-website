# Rekar Group — Website + CMS

Premium Kurdish Sorani (RTL) website and custom CMS for **Rekar Group** (Digital Agency & Technology).

## Stack

- Next.js App Router + TypeScript + Tailwind CSS
- Supabase (PostgreSQL, Auth, Storage)
- Server Actions, Zod, Tiptap, Framer Motion

## Quick start

```bash
npm install
cp .env.example .env.local
# Fill in Supabase keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the public site.  
Admin: [http://localhost:3000/admin](http://localhost:3000/admin) (requires login).

Without Supabase credentials the **public site** uses demo seed data. Admin mutations require a configured project.

## Supabase setup

1. Create a Supabase project.
2. In the SQL Editor, run in order:
   - `supabase/migrations/001_initial_schema.sql`
   - `supabase/seed.sql`
3. Create an Auth user (email/password) in Authentication.
4. Promote that user:

```sql
update public.profiles
set role = 'super_admin', is_active = true
where email = 'your-admin@email.com';
```

5. Set `.env.local`:

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

6. Confirm Storage bucket `media` exists (created by migration).

## Posts CMS

Dedicated routes:

- `/admin/posts` — list with search/filters/bulk actions
- `/admin/posts/new` — create
- `/admin/posts/[id]` — edit with autosave, schedule, preview
- `/admin/posts/preview/[id]` — draft preview (admin only)

After initial schema, also run:

- `supabase/migrations/002_posts_analytics.sql`

Cron helper: `GET /api/cron/publish-scheduled` publishes due scheduled posts.


Place real logos at:

- `public/brand/logo.png`
- `public/brand/logo-mark.png`

Placeholders are generated by `node scripts/make-brand.js`.

## Security notes

- Never expose `SUPABASE_SERVICE_ROLE_KEY` to the client.
- Admin routes are protected by middleware + server-side RBAC (`super_admin` | `admin` | `editor`).
- RLS policies restrict anonymous users to published content and contact inserts.
